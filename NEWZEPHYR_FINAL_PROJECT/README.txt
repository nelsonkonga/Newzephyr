OUVRIR LE PROJET
1. Gardez ce dossier entier. Ne sortez pas Newzephyr_Final.fcproj de NEWZEPHYR_FINAL_PROJECT.
2. Ouvrez Newzephyr_Final.fcproj avec FilmCraft 0.15 ou une version plus récente.
   Le fichier est au schéma 15, le même que le projet d'origine (FilmCraft 0.15.0).
   Une version plus récente l'ouvre et peut le mettre à jour à l'enregistrement.
3. Les médias sont en chemins relatifs, résolus depuis le dossier du projet :
   MEDIA/   images et vidéos d'origine
   GRAPHICS/  logo détouré et fichiers de marque
4. Si un plan s'affiche hors ligne : Fichier > Lier les médias, puis indiquez le dossier MEDIA
   (et GRAPHICS pour le logo). Les noms de fichiers n'ont pas été changés, sauf
   Entrepreneur_reviewing_smartphone_93740c29.mp4, dont le nom d'origine contenait
   des points de suspension.

TEXTE
Tous les titres sont des calques de texte FilmCraft, police Inter.
On les modifie avec l'outil Texte ou dans le panneau Propriétés.
Les mouvements sur les photos sont des images clés de l'effet Motion
(échelle et position). Les fondus sont la transition native Cross Dissolve, 12 images.

LIMITES, DITES CLAIREMENT
- FilmCraft n'était pas installé sur la machine qui a préparé ce dossier.
  Le projet a été écrit dans le format natif observé (schéma 15) et vérifié :
  chemins, durées, pistes, absence de trou sur la piste image, textes.
  Il n'a pas été rouvert dans l'application FilmCraft.
- PREVIEW.mp4 est un aperçu de vérification rendu avec ffmpeg.
  Ce n'est pas un export FilmCraft et il ne remplace pas le projet.
- Le projet d'origine référençait aussi une vidéo
  « Follow and Click the link in my bio… » qui n'était pas dans le dossier Drive.
  Elle n'a pas été inventée. L'accroche utilise file.mp4, le seul autre plan fourni :
  une femme regarde son téléphone. Ce plan est carré (480×480). Il est cadré
  en bande nette sur un fond flou, pour remplir le 9:16 sans l'étirer.
- Les « icônes » des bénéfices sont des ellipses natives, pas des pictogrammes dessinés.
- La sauvegarde byte à byte du projet d'origine est dans BACKUP/ si le fichier
  Untitled.fcproj s'y trouve. Sinon, l'original reste le fichier Drive
  Untitled.fcproj (FilmCraft 0.15.0, 4 novembre 2026, 23:41 UTC).
